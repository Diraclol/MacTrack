# Screenshots

Drop the app screenshots here as PNGs with these exact filenames (referenced by the repo-root
`README.md` gallery):

- `dashboard.png` — the Dashboard
- `food-log.png` — the Food Log tab
- `food-detail.png` — a food detail screen (rings + portions)
- `search.png` — the food search
- `splash.png` — the splash screen (optional)

Phone screenshots (roughly 1080x2400) look right at the ~220px width the gallery uses. Once the files
are here with these names, the README gallery renders automatically.
